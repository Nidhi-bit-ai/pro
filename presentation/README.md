# MNIT RAG Presentation

This folder contains a reproducible PowerPoint deck for the MNIT document RAG project.

## Files
- `create_presentation.py` — source script that generates the deck.
- `MNIT_RAG_Presentation.pptx` — generated presentation.
- `requirements.txt` — lightweight dependency list.

## Regenerate
From the repository root (`/home/runner/work/pro/pro`):

```bash
python -m pip install -r presentation/requirements.txt
python presentation/create_presentation.py
```

The deck will be written to:
`/home/runner/work/pro/pro/presentation/MNIT_RAG_Presentation.pptx`
